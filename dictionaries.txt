dictionaries
  They are always stored as {keys,values}
Theory:
they are mutable , ideal for counting large data structures
code:
  # Choose file name
fname = input("Enter file name: ")
if len(fname) < 1:
    fname = "mbox-short.txt"

handle = open(fname)

counts = dict()

for line in handle:
    line = line.rstrip()
    if not line.startswith('From '):
        continue
    words = line.split()
    email = words[1]
    counts[email] = counts.get(email, 0) + 1

# Maximum loop to find the most prolific committer
bigcount = None
bigword = None

for word, count in counts.items():
    if bigcount is None or count > bigcount:
        bigcount = count
        bigword = word

print(bigword, bigcount)
  concept learnt:
  using .get() method to implement counting patterns 
  using .lstrip(), .rstrip()
