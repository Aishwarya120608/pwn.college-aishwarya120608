perceiving permissions 
In this challenge, we add and remove permissions, 'chmod' can also be  used to simply set permissions altogether. It overwrites the old ones using '=' instead of '-'or'+'
solve
 - The challenge required modifying permissions for user (u), group (g), and world/others (o) across 8 random target rounds using exact assignment (=) and comma chaining in chmod.
- In each round, the program specified the target permission string (e.g., r--r---w-). We analyzed each triad (u, g, o), constructed the corresponding chmod u=...,g=...,o=... /challenge/pwn 
Finally, we modified /flag permissions using chmod u=r /flag and retrieved the flag with cat /flag.
