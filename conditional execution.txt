Learning how to use conditional statements in python program
theory:
conditional statements are (if,elif,and else) we use these to see if the given statements abide by the conditions if true it will execute otherwise else part will execute
code 
hrs = input("Enter Hours:")
rate= input("enter rate")
hrs=float(hrs)
rate=float(rate)
if hrs<=40:
    pay=rate*hrs
else:
    regpay=40*rate 
    overtime=hrs-40 
    pay1=overtime*(1.5*rate)
    pay=regpay+pay1
print(pay)
